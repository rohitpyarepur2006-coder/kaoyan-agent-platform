# 当前接口与边界

日期：2026-10-13。本文件描述**已实现代码**；完整目标见[搭建文档](../考研Agent平台搭建文档.md)。

## 已可运行

| 接口 | 行为 |
| --- | --- |
| POST /api/auth/register、POST /api/auth/login | username/password；返回token、expiresAt及含student角色的user |
| GET /api/auth/me、POST /api/auth/logout | Bearer会话身份与注销 |
| POST /api/tasks | input、可选taskType和subject；省略类型按knowledge_qa；仅知识问答可以进入Agent |
| GET /api/tasks?page=0&taskType=knowledge_qa | 每页20条本人记录，可按类型筛选 |
| GET /api/tasks/{id} | 本人任务，跨账号404 |
| GET /api/knowledge/points、GET /api/questions | 读取演示知识点和可练单选题；支持科目、知识点、难度筛选 |
| POST /api/practice-sessions | 创建chapter、random、wrong或favorite练习批次 |
| GET /api/practice-sessions、GET /api/practice-sessions/{id} | 查询本人批次、固定题序、进度、草稿状态与判分状态 |
| PUT /api/practice-sessions/{id}/progress | 使用revision保存当前题号和未提交草稿 |
| POST /api/practice-sessions/{id}/items/{itemId}/hints | 按顺序获取两级审核提示并记录最高提示级别 |
| POST /api/attempts | 以clientRequestId幂等提交，Java确定性判分并更新错题 |
| GET /api/wrong-questions、GET /api/favorites | 查询本人错题和收藏；两者均可作为新批次题池 |
| GET /api/health | Java进程存活，不等于全链路就绪 |

用户名3—32位字母、数字、下划线或短横线，统一小写；密码至少8字符且UTF-8不超过72字节。会话有效期24小时，前端sessionStorage保存令牌；数据库只存摘要。默认每账号每UTC日30项任务、每分钟6项。

任务请求input去除首尾空白后1—8000字符，知识问答不能携带preferences或attemptId。用户不能提供ownerId或context。支持四科subject枚举；未知类型、字段与科目返回400。

任务保存taskType及resultSchemaVersion=2。结果含taskId/status/mode/answer/steps/sources/followUp/latencyMs/releaseId/data。引用含真实演示元数据与retrievedAt。completed、needs_input、unsupported、failed为终态；HTTP200不保证领域任务完成。

## 刷题、错题与统计

当前内置四科共12道稳定编号的自编演示单选题，每科3道，覆盖easy、medium。题目、解析、来源标签和两级提示只用于功能演示，均标注为“408自编演示题（待课程资料负责人复核）”；不属于正式真题或已审核正式题库。

- 所有目录、批次、作答、错题、收藏和统计接口需要登录。跨账号读取批次、作答或错题返回404。
- 题目列表、题目详情和未提交批次项目不返回标准答案或解析。提交后返回本次确定性判分、解析和来源标签。
- `chapter`按稳定顺序组题，`random`无放回抽取并固定本批次顺序，`wrong`只从本人的待复习错题组题，`favorite`只从本人收藏组题。候选不足返回实际数量，零候选返回400 `EMPTY_PRACTICE_POOL`。
- 草稿保存要求提交当前`revision`；旧版本返回409 `STALE_REVISION`，避免多标签页静默覆盖。已提交项目和已结束批次不可再修改。
- level 2提示必须在level 1之后获取。提示使用写入作答；使用提示后的答对不推进错题的连续独立正确次数。
- 判分只比较服务端题目版本的标准选项，不调用模型。相同`clientRequestId`和相同内容返回原作答；复用编号但改变内容返回409 `REQUEST_CONFLICT`；同一批次项目不能重复判分。
- 批次项目及作答读取独立的`QuestionVersion`内容，当前题目更新不改变旧题干、提示、判分或历史解析。带批次作答校验绑定版本；无批次只接受当前版本。缺失或所属题目不符返回409 `QUESTION_VERSION_UNAVAILABLE`，不回退当前内容。初始化及后续审核发布边界见[题目历史版本契约](题目历史版本契约.md)。
- 错答自动进入`reviewing`。之后连续两次无提示答对标记为`mastered`，再次答错恢复`reviewing`。该状态只表示平台复习规则。
- 全部题目提交后批次自动完成，也可提前结束。未答题不计作错误或错题。批次结果分别展示总正确率与独立正确率。

## 题目录入与审核

管理员题目接口现已支持分页目录、详情、新草稿、带expectedVersionId修订、版本历史、通过／驳回及审核日志，具体字段、依赖和验收见[题目录入与审核契约](题目录入与审核契约.md)。替换原题目录入占位DTO，仅支持一个知识点，必须登记来源、使用权限和获取日期；不接受客户端指定作者、审核人或草稿状态。学生403，未登录401；版本冲突／重复审核409，非法输入400。

草稿内容和当前可练版本分离，审核通过不等于发布。新题始终inactive，已有演示题修订不改变学生目录或旧批次。其余管理模块仍为占位。

## 仍为占位的业务模块

profile、招生catalog、recommendation、study以及资料／招生管理和共享发布仍只有控制器、契约或占位服务。题目发布、撤回与正式版本迁移也未实现。对应目标路径参照搭建文档第7节。

- 需要登录；未登录401。学生请求/api/admin/**返回403。
- 已通过认证和当前DTO校验的占位操作返回501，code为FEATURE_NOT_IMPLEMENTED。不生成档案、院校、推荐、综合学习统计或管理发布记录。
- Java择校／错题任务同样返回501，不请求Python、不消耗任务配额。preferences和attemptId已保留入参位置，完整校验及本人业务查找待实现。
- 当前刷题DTO覆盖演示闭环需要的字段，尚未实现题目撤回、历史发布版本和Agent错题辅导上下文。新增字段时同时更新校验和服务接口；不要通过关闭未知字段校验容纳新字段。

## Python内部接口

POST /internal/run需X-Internal-Key，输入taskId、input、taskType、releaseId与context。类型分别为knowledge_qa、school_recommendation、wrong_question_tutor；context按类型校验，不接受伪造ownerId。省略类型与context兼容基础文本请求。

当前仅demo-408-v1演示版本。knowledge_qa默认关键词检索并可按科目过滤；demo直接返回标注未审核的资料，model使用相同演示资料验证适配层。择校与错题入口直接unsupported，不调用模型。

release与检索使用独立Protocol，当前无BM25、管理发布或正式资料包加载。首次领域实现需新增审核与版本流程，不能把演示版本称为正式发布版本。

## 失败与未来兼容

输入或空题池错误400、会话错误401、权限403、私有资源不可访问404、重复账号／过期草稿／重复判分409、限额429、未实现501。Agent离线或输出异常保存failed，返回任务编号；重启将遗留running标记中断失败。浏览器超时不取消后台操作，先查历史或批次。

本项目是新库，不导入基础工程数据库。当前H2／Hibernate update仅用于骨架，本次没有历史数据库迁移；正式业务上线前需增加版本化迁移，并分别验证PostgreSQL。
